IntelliEvent Lightning 3.0



Be one of the first to use the new Lightning to take your business to the next level!

Lightning has been enhanced to include a new user interface, user notifications, a new quote wizard, and a global labor bookings page among other features.

Free Demo Lightning FAQ's

  • User Interface
  • Quoting
  • Job Order
  • Finance
  • Inventory
  • Reports
  • Clients
  • Users
  • Printing

  • Global User Interface enhancements increase ease of use and add efficiency

    New global header bar (main navigation)


    • Upper right icons link to:

    • - Quick Add
    • - Support
    • - Notifications
    • - User Settings

    • Select recent jobs/clients feature in expanded global header bar

      Notifications

    • Systemwide Notifications

    • - System Generated
    • - Admin Generated
    • - IntelliEvent Support Generated

  • Quoting Functionality

    • Quote Wizard (combination of the previous product selector and product manager)

    • - Allows you to add products to the order using drag-and-drop
    • - Allows you to easily modify all data related to items on the order
    • - Enhanced functionality within the grid to be able to change sort order and room arrangement

    • Global labor booking page

      • - Allows you to book labor in a single place for any job

  • Job Order

    • Page reformatting to improve project view without scrolling

    • New job level discount feature: bottom line discount

    • New features for insurance certificates

    • Enhanced venue commission structure and reporting

    • Client Quick Add

      • Client Quick Add

    • - Allows for a brand new client to be added on the fly from the job page

  • Finance

    • Purchase Orders:

    • - Purchase order receiving module
    • - Page reformatting to match new UI

  • Inventory

    • - Can view item availability by the minute instead of by the day

    • Logistics Page:

    • - Notifications
    • - Grid color coding

    • Maintenance:

    • - Improved maintenance process logic

    • Manufacturers:

    • - Added a manufacturer edit and creation area to the system options

    • Kits:

    • - A Kit List has been added to the Inventory tab

      • Added photo/image link to inventory manager line items

  • Reports

    New Reports:

    • - Equipment detail report
    • - Labor export report
    • - Project List report
    • - Category Summary report
    • - Product sale report
    • - Hotel commission report by venue
    • - Potentials Report

    Changes to Existing Reports:

    • - New format for job status filter allows you to pick the exact status’ you want on the report
    • - Change to Items Not Returned to filter only by return date

  • Clients

    • - Client Merger Tool (for syncing duplicate clients)
    • - Enhanced CRM Notes/Tasks
    • - Added Potentials area for tracking sales opportunities by client

  • Users

    Security Enhancements:

    • - New user profile change that allows all users to change their own password and details
    • - Can navigate to user page from the User Icon in global header bar
    • - Enhanced password security features

  • Printing

    Expanded:

    • - Checkbox options have been included in all relevant grid types
    • - Can navigate to user page from the User Icon in global header bar
    • - Alias may now be used with most all system grids
    • - Alias options have been added to product names, product notes and Designations
    • - Deposit Invoice expanded to work with most all grid types
    • - No Line Item Pricing Options has been expanded to work with most all grid types
    • - Labor option to print with tasks added
    • - Misc. Template configuration options added and enhanced
    • - Office logo
    • - One document can now print with any office logo instead of requiring multiple documents
    • - New template editor
